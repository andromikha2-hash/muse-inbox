## The reel Andro sent — Part 22: Hypothesis Testing (Oct 13, 2026, 3,480 likes)

Start from the null hypothesis: the strategy's true average return is zero, so there is no edge. Ask how often pure luck would produce a result at least as extreme as yours if that were true. The t statistic is the average return divided by its standard error; the p value is the probability of a t statistic at least that far from zero when there is really no edge. At 95% confidence a result counts as significant when p is below 5%, matching a 95% confidence interval that does not include zero. In the video's simulation (a real edge built in: true Sharpe 1, daily swings 1%, five years), the run reached t = 1.50, p = 13.3%, and the interval ran from -0.013% to +0.096% — it included zero, so not significant at 5% even though the edge was real, because the run only showed Sharpe 0.67 and five years was not enough. Rule of thumb given: t is about the yearly Sharpe ratio times the square root of the number of years, so with Sharpe 1 you need about four years to reach t = 2. Biggest trap: testing many rules — test 100 strategies with no edge and about 5 still pass at 5% by luck (in their run, 7 did). A p value is not the probability the strategy works; the test assumes independent returns and a market that stays the same, and a real edge can still be too small to survive trading costs. All numbers are from one simulated run (seed 22), no real market data, no strategy recommendation.
